# Казка

Дитячий навчальний застосунок українською для першого класу: 10 інтерактивних пригод, читання та цікаве додавання в межах 20. Expo / React Native / TypeScript.

Тестова вебверсія: https://cazka-dytyachi-pryhody.amberode2.chatgpt.site

`npm ci` → `npm run web`.

**Готовий сайт уже лежить у папці [`dist/`](dist/)** — його можна відкривати чи публікувати без збирання (точка входу `dist/index.html`, шляхи відносні, тож працює і в корені домену, і в підпапці). Після змін у коді перезібрати: `npm run build:web`.

Можливості, перевірки та відомі обмеження: [DEVELOPMENT.md](DEVELOPMENT.md).
