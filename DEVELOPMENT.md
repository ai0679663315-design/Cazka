# Казка — тестова версія

Окремий проєкт React Native / Expo. Family не використовується.

## Запуск

Node.js 22+, `npm ci`, `npm run web`. Нативний запуск: `npm start` і Expo Go. Для Android APK потрібен EAS Build; APK не створено й нативні сценарії не перевірено.

## Перевірки

`npm run typecheck`, `npm test`, `npm run build:web`.

## Що працює

- Знайомство з ім’ям, віком і вибором інтересу (тварини, космос, море, динозаври, казки, машини); локальне збереження. Профілі попередньої версії підхоплюються автоматично.
- **10 пригод** (`src/stories.ts`): по 7 кроків — вступ, вибір шляху (впливає на фінал), три задачі-розповіді з героями історії, записка для читання з питанням. За кожну пройдену пригоду — наліпка в альбом.
- **Математика 1 класу** (`src/math.ts`), 5 рівнів: до 5 → до 10 → склад числа до 10 → до 20 без переходу → з переходом через десяток.
  Типи завдань: порахуй предмети на картинці, вибери відповідь, загадкове число (4 + ? = 9), будиночок числа, задача-розповідь, порівняння (<, =, >), «скільки залишилось».
  Відповідь — великими картками або голосом. Після першої помилки — підказка та намистинки (рамка по 10), після другої — розв’язок. Зірочки за відповідь з першої спроби, серія правильних відповідей.
  Рівень змінюється сам: 4 з 5 правильно — вище, 3 помилки з 4 — нижче; батьки можуть обрати рівень вручну.
- Стартова перевірка: 4 приклади різних рівнів і текст; за результатом обирається початковий рівень.
- Окремі заняття: «Математична майстерня» (8 завдань) і читання записок героїв.
- Темп читання за фактично виміряним часом, питання на розуміння з другою спробою.
- Альбом наліпок, зірочки, історія останніх 100 занять, помилки та статистика навичок.
- Озвучення українською (можна вимкнути); голосові відповіді в сумісних браузерах.
- Батьківський екран із локальним PIN, рівнем математики, налаштуванням перерви та очищенням профілю.

## Планшет (вебверсія)

- Картки відповідей і кнопки збільшені для пальців; на планшеті будь-якої орієнтації головна та практика в два стовпці.
- Предмети на картинці можна торкатися — з'являється номер, озвучується лічба.
- Вихід із заняття — подвійним натисканням («Точно вийти?»), щоб дитина не загубила пригоду випадково.
- Короткі звуки за правильну відповідь і фінал (Web Audio, вимикаються разом зі звуком).
- Озвучення «розблоковується» першим дотиком (вимога iPad/Android). На батьківському екрані видно, чи є на пристрої український голос.
- `public/index.html` + `manifest.json` + іконки: «Додати на головний екран» відкриває Казку на весь екран, без зуму подвійним дотиком і меню довгого натискання.

## Структура

- `App.tsx` — стан, збереження й екрани.
- `src/math.ts` — генератор завдань, рівні, адаптація; `src/stories.ts` — пригоди; `src/profile.ts` — профіль і міграція.
- `src/components.tsx` — картка задачі, читання, намистинки, будиночок, доріжка пригоди; `src/StoryPlayer.tsx` — програвач пригоди; `src/theme.ts` — стилі.
- Тести: `src/*.test.ts` (межі чисел для кожного рівня, правильність відповідей, відмінювання, тексти пригод без незаповнених місць).

## Межі версії

Готові сюжети, а не генеративний AI-діалог. Пам’ять локальна (AsyncStorage), без синхронізації. PIN захищає від випадкових змін, не є серверною автентифікацією. Темп читання залежить від натискання кнопок, вимова автоматично не перевіряється. Браузерне розпізнавання голосу залежить від дозволу, мови й сервісу браузера; записів у застосунку немає. Нативного розпізнавання для Android/iOS немає. Нагадування про перерву не блокує заняття. Перерване заняття зберігає відповіді у статистиці навичок, але до історії потрапляють лише завершені заняття.

Не вводьте API-ключі у клієнтський код. AI та міжпристроєва пам’ять потребують серверного підключення.
