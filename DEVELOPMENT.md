# Запуск і перевірка Cazka

## Поточний стан
- Expo + React Native + TypeScript
- Одноразове знайомство; ім'я, інтереси та результати зберігаються в AsyncStorage на пристрої
- Три сюжетні пригоди з арифметикою та читанням
- Озвучення українською через expo-speech
- Голосове введення в браузері через Web Speech API за наявності підтримки; текстове введення як запасний варіант

## Локальний запуск
```bash
npm install
npx expo start --web
```
Для Android Expo Go: `npx expo start --android` (голосове введення в нативному режимі поки недоступне).

## Перевірка вручну
1. Запустити чистий профіль, назвати ім'я, вік та інтерес.
2. Закрити й відкрити застосунок: знайомство не повинно повторюватися.
3. Почати пригоду, прослухати приклад, ввести правильну й неправильну відповідь.
4. Прочитати записку та відповісти на запитання.
5. Перезапустити застосунок: лічильники пригод і результатів мають зберегтися.
6. У Chrome з дозволеним мікрофоном перевірити голосове введення. За відсутності підтримки має залишатися текстовий варіант.

## Наступний етап
- Нативне розпізнавання мовлення Android/iOS з явним дозволом мікрофона
- Серверний AI-діалог із короткою пам'яттю контексту, окремою базою прогресу й батьківським контролем
- Захист дитячих даних: мінімальний збір, видалення профілю, згода батьків, відсутність зберігання сирого аудіо за замовчуванням
- Автоматизовані тести й реальна перевірка на Android

Цей коміт не підтверджує проходження збірки: GitHub-конектор записує код, але не запускає Expo.
